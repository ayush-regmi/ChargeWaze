# ADR 0000: Template

- Status: template (copy this file for new ADRs)
- Date: YYYY-MM-DD
- Deciders: who signed off
- Supersedes: ADR number, if any
- Superseded by: ADR number, if any

## Context

What is the problem? What forces are at play (technical, product, timeline, cost, licensing)? Link relevant docs under [`docs/`](..) and any upstream issue.

## Decision

The decision, in one or two sentences. Written as an imperative: "We will…".

## Consequences

What becomes easier? What becomes harder? What do we have to maintain, monitor, or revisit?

## Alternatives considered

Each alternative with a one-line "why not now" explanation. If the alternative is still a plausible future direction, note the trigger that would cause us to reopen the decision.

## References

External docs, blog posts, API references, and (importantly) the official vendor documentation for anything third-party.
